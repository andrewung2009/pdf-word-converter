FAQ

Good to know.

Which formats are supported?

Word documents in the modern .docx format and PDFs. The old binary .doc format is not supported. In Word, use File → Save As → Word Document (.docx) first.

How close will the conversion be?

Word → PDF keeps the page layout, tables, and images very close to the original. PDF → Word rebuilds editable text, headings, lists, and images; complex multi-column designs may shift. Choose “Exact layout” to keep every page looking identical as images.

What about scanned PDFs?

A scanned PDF has no text layer, so editable output would be empty. The app detects this and suggests “Exact layout” mode, which places each page image into Word. OCR is not included.

Why does the PDF look slightly different from Word?

The browser can only use fonts available to it. The app includes Carlito and Caladea, which match Calibri and Cambria, but unusual fonts or advanced Word effects may render differently.

Is there a file size limit?

There is no server limit because nothing is uploaded. Around 25 MB or 200 pages is a comfortable range; larger files work if your device has enough memory.

Can I get selectable text in the PDF?

Yes. The downloaded PDF includes a searchable, selectable text layer. For fully vector text, use Print / Save as PDF, which uses your browser’s PDF engine.

Does it work on my phone?

Yes, in current versions of Chrome, Edge, Firefox, and Safari. Large files are best handled on a computer.
